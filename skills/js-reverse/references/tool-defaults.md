# Tool Defaults

- `js-reverse_list_network_requests`: check the first page of default results first; paginate only if insufficient
- `js-reverse_search_in_sources`: defaults to `excludeMinified=true`
- `js-reverse_get_script_source`: read only small fragments; for full source prefer pairing with `js-reverse_save_script_source`
- `js-reverse_break_on_xhr`: fill in only URL fragments that will hit reliably
- `js-reverse_get_paused_info`: start with `frameIndex=0` by default
